public void Repeat(int x)
{
    if (x < 0)
    {
        x = x % width;
        x = width + x;
    }
    else
        x = x % width;
    return x;
}

The river keeps the evening in its pocket.
It spends the light on stones,
then folds the dark along the bank.

Where the grass is still deciding
whether to be water,
a heron stands in the shallows
and does not choose.

By morning the pocket is empty.
The stones remember the light.
